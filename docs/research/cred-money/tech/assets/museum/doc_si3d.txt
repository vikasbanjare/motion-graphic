# api | file\_search

fetches content based on a query/filter

get

```
https://3d-api.si.edu/api/v1.0/content/file/search
```

## Parameter

| Field | Type | Description |
| --- | --- | --- |
| q optional | String | the query term you would like to issue. examples (q=Mandible,q=Space Shuttle,q=Crab) |
| model\_url optional | String | the model identifier, can be used with or without prefix (3d\_package:40cf5b52-0b21-4063-95fc-aa07998eb4dd, 40cf5b52-0b21-4063-95fc-aa07998eb4dd) |
| file\_type optional | String | the file type to filter results against.  Allowed values: `jpg`, `glb`, `ply`, `zip` |
| file\_size optional | String | the file size in bytes to filter results against. Best used as a range query (file\_size:[0 TO 10000])  Allowed values: `integer_in_bytes` |
| file\_quality optional | String | the quality type to filter results against.  Allowed values: `Low`, `Medium`, `High`, `Thumb`, `Low_resolution`, `Medium_resolution`, `Full_resolution`, `Water_tight` |
| model\_type optional | String | the model type to filter results against.  Allowed values: `glb`, `ply`, `obj`, `gltf`, `f3z`, `blend`, `stl` |
| gltf\_orientation\_compliant optional | Boolean | restrict results to gltf\_orientation\_compliant files.  Allowed values: `true` |
| draco\_compressed optional | Boolean | restrict results to draco\_compressed files.  Allowed values: `true` |
| owning\_unit optional | String | restrict results to owning unit.  Allowed values: `CHNDM`, `DPO`, `FSG`, `NASM`, `NMAAHC`, `NMAfA`, `NMAH`, `NMNHEDUCATION`, `NMNHFISHES`, `NMNHHERPS`, `NMNHINV`, `NMNHMAMMALS`, `NMNHPALEO`, `NPG`, `OFEO-SG`, `SAAM`, `SAO` |
| start optional | Integer | the start of the result set.  Default value: `0` |
| rows optional | number | the number of rows in a result set.  Default value: `10`  Size range: `0..1000` |
