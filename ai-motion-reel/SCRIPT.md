# Reel script — "Claude se motion graphic video"

**Format:** 9:16 vertical (1080×1920), 30 fps, ~25s. Instagram Reels / YouTube Shorts.
**Audience:** Indian creators, small business owners, marketers. Hinglish, Latin script (how most Indian Reels are captioned).
**Goal:** Stop the scroll, show the workflow is real, drive comments.

| # | Time | Scene | On-screen text | Why it works |
|---|------|-------|----------------|--------------|
| 1 | 0–3s | **Hook** | "Agency ka quote: ~~₹50,000~~" → "Ab? **Ek prompt.**" | Price shock + strike-through is a pattern interrupt. Indian audiences are price-anchored; a rupee number stops the thumb. |
| 2 | 3–7s | **Problem** | "Agency → 2 hafte" / "Freelancer → ₹15k+" / "Aapko reel → **kal** chahiye 😩" | Names the pain every creator feels: slow + expensive. Quick stacked lines keep pace. |
| 3 | 7–11s | **Reveal** | "**Claude** + Remotion" / "Aap bolo. Claude code likhta hai. Video ban jaata hai." | Names the tool once, simply. Three short beats, easy to remember. |
| 4 | 11–18s | **How (3 steps)** | ① "Idea Hinglish mein likho" ② "Claude hook + script + animation banata hai" ③ "Ek command → MP4 ready" + typed prompt bubble | Shows the process is concrete, not magic. Numbered steps are save-worthy. |
| 5 | 18–22s | **Proof** | "Yeh video bhi aise hi bana hai." / "100% code · 0 After Effects" | Meta-proof: the viewer is watching the result. Builds trust. |
| 6 | 22–25s | **CTA** | "Comment karo **VIDEO**" / "Poora prompt DM mein bhejunga 🚀" / "Save kar lo 🔖" | Comment-keyword CTA boosts reach and gives you leads. Save prompt adds a second signal. |

## Suggested voiceover (optional, Hinglish)

> Agency ne motion graphic video ka quote diya — pachaas hazaar rupaye. Ab? Bas ek prompt.
> Agency mein do hafte, freelancer pandrah hazaar se upar, aur aapko reel kal chahiye.
> Solution: Claude plus Remotion. Aap bolo, Claude code likhta hai, video ban jaata hai.
> Step one: apna idea Hinglish mein likho. Step two: Claude hook, script aur animation banata hai. Step three: ek command, aur MP4 ready.
> Aur haan — yeh video bhi bilkul aise hi bana hai.
> Comment karo "VIDEO", poora prompt DM mein bhejunga. Save kar lo!
